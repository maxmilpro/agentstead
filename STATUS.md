# Status

**Current phase:** Field research and problem validation

---

## What this is right now

Agentstead is a vision-stage project. The `docs/` folder contains the north star — where this is heading and why. The path to get there is being built from lived experience, not theory.

## What's happening

Running a real-world experiment: deploying a shared AI agent for a fluid, multi-user community (a coworking floor / accelerator). The goal is to understand the collaborative agent problem from the inside — where existing tools break down, what "no admin overhead" actually requires, how tribal knowledge gets captured and stays accurate when membership is fluid.

Observations and raw notes will accumulate in `notes/` as the experiment runs.

## What comes next

After the experiment (target: 4-6 weeks of operation):
- Document what worked, what didn't, what a custom build would need to do differently
- Revise the MVP PRD with real design constraints instead of hypothetical ones
- Decide whether to build something custom

## Want to follow along or collaborate?

This project is looking for people who've felt the same problem — teams, communities, or small organizations where AI tools exist but aren't designed for shared, fluid, multi-user use. If that's you, open an issue or reach out.
